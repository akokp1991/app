# پنل مرز باشماق — نسخه اندروید

اپ اندروید (WebView) برای پنل مدیریت. همه‌ی امکانات پنل را دارد:
دانلود اکسل/PDF/بکاپ، آپلود فایل برای بازیابی، پنجره‌های تأیید حذف، کشیدن برای رفرش،
باز شدن لینک واتساپ در خود واتساپ، و صفحه‌ی خطا با تلاش دوباره.

## ساخت APK بدون نصب هیچ برنامه‌ای (پیشنهادی)
۱. در github.com یک حساب رایگان بسازید و یک مخزن (Repository) جدید، مثلاً `bashmaq-panel` بسازید.
۲. محتوای همین پوشه (نه خودِ zip) را در مخزن آپلود کنید: Add file ← Upload files.
   پوشه‌ی مخفی `.github` هم باید آپلود شود (اگر نشد، فایل `build-apk.yml` را دستی در مسیر `.github/workflows/` بسازید).
۳. تب **Actions** ← «Build APK» ← **Run workflow**. حدود ۳ تا ۵ دقیقه صبر کنید.
۴. روی اجرای سبزشده کلیک کنید، پایین صفحه در بخش Artifacts فایل `bashmaq-panel-apk` را دانلود و از zip خارج کنید.
۵. فایل `app-debug.apk` را در گوشی نصب کنید (اجازه‌ی «نصب از منبع ناشناس» را بدهید).

## ساخت با Android Studio
۱. Android Studio را نصب کنید، `File ← Open` و همین پوشه را انتخاب کنید و صبر کنید Sync تمام شود.
۲. `Build ← Build Bundle(s) / APK(s) ← Build APK(s)`.
۳. فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## اولین اجرا
اپ آدرس سرور را می‌پرسد، مثلاً `192.168.1.10:5000` یا `https://panel.example.com`.
بعد با همان نام کاربری و رمز پنل وارد شوید. آدرس را بعداً از منوی ⋮ ← «تنظیمات سرور» می‌توانید عوض کنید.

## نکته‌های مهم
- گوشی باید به سرور دسترسی داشته باشد: یا روی همان Wi‑Fi باشد، یا سرور آی‌پی/دامنه‌ی عمومی داشته باشد.
- برای اتصال از بیرون از خانه/محل کار، حتماً پنل را پشت HTTPS بگذارید و روی سرور `COOKIE_SECURE=1` تنظیم کنید.
  (اپ http را هم قبول می‌کند، اما رمز روی اینترنت بدون رمزگذاری می‌رود.)
- برای اینکه در اپ مدت بیشتری وارد بمانید، روی سرور متغیر `SESSION_HOURS` را مثلاً `720` (۳۰ روز) بگذارید. پیش‌فرض ۸ ساعت است.
- منوی ⋮ ← «خروج و پاک‌کردن اطلاعات ورود» نشست ذخیره‌شده‌ی اپ را پاک می‌کند.
- اعلان فوری (Push) ندارد؛ اعلان‌های آنی همچنان از ربات تلگرام می‌آید.
